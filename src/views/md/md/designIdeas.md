# DragVueForm 设计思路

我是 `DragVueForm` 的作者 - zeMinng。

## 项目背景

在日常前端开发中，表单的创建和维护是一项重复且繁琐的工作。为了提升开发效率、降低出错率，并让非技术人员也能参与表单设计，我决定开发一款基于拖拽的可视化表单生成器 —— DragVueForm。

## 技术选型

React + Vite + TypeScript  + antd + SCSS + zustand + @dnd-kit/core  等
